📋 功能介绍
本工具用于：录入订单号与联系号码，批量生成可拨号的静态压缩二维码与活码；支持批量导入/导出数据，活码模式下更新数据无需重新生成二维码。数据默认保存在浏览器本地，活码模式需配套数据文件提供内容。
⚠️ 违规使用告知
1. 本工具仅可用于本人合法、合规的业务场景；
2. 严禁用于骚扰电话、电信诈骗、批量外呼骚扰、隐私窃取等任何违法违规行为；
3. 使用者对所录入的全部号码与订单数据承担全部法律责任；
4. 禁止采集、存储、传播未获授权的他人个人信息；
5. 若用于任何非法用途，一切法律后果由使用者自行承担。

活码使用步骤（订单变更后只需重复第1步）：
① 在下方填入 GitHub Token（首次填写后自动保存）
② 点「一键上传到线上」→ 自动更新线上 live-data.json（无需手动下载拖拽）
